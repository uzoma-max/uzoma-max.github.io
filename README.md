# uzoma-max.github.io

My personal portfolio website: who I am, what I've worked on, and how to reach me.

**Visit it:** https://uzoma-max.github.io/

## What's inside

- About me and my work as a Product Manager in fintech
- My projects, with links to live demos and code
- Experience, skills, education and certifications
- Contact links

## Built with

Plain HTML and CSS, no frameworks. It works on phones and supports dark mode, and it's hosted for free on GitHub Pages.

## Run it locally

```bash
git clone https://github.com/uzoma-max/uzoma-max.github.io.git
cd uzoma-max.github.io
open index.html   # on Windows: start index.html
```
